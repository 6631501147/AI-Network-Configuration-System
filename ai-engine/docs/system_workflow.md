# System Workflow

1. User creates network topology in GNS3
2. User captures topology screenshot
3. AI analyzes topology
4. AI generates Python automation script
5. Python script configures routers automatically
6. Python script configures VPCS automatically
7. OSPF routing is configured
8. Connectivity verification is performed
9. Results are saved in results folder
