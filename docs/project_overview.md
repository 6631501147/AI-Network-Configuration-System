# AI-based Automatic Network Configuration System

## Project Description
This project is an AI-based network automation system developed using Python and GNS3.

The system automatically configures routers and PCs inside a simulated enterprise network topology.

Users create a topology in GNS3 and provide a topology screenshot to the AI system. The AI generates Python automation scripts that configure network devices automatically.

## Main Features
- Automatic router configuration
- Automatic VPCS configuration
- Automatic OSPF routing configuration
- Connectivity testing using ping
- Network automation using Python
- GitHub integration for version control

## Technologies Used
- Python
- GNS3
- Netmiko
- Paramiko
